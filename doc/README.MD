# Documentation

Les PDF et documents historiques sont conservés pour référence et peuvent décrire une ancienne interface. Les guides utilisateurs actuels sont dans `appli/` et accessibles depuis la page À propos. Pour une installation ou migration, commencer par [INSTALLATION.md](../INSTALLATION.md) et les documents techniques de ce dossier. Certains comptes rendus techniques mentionnent des chemins de développement ou anciennes listes de livraison qui ne sont pas nécessaires au fonctionnement du dépôt public.
